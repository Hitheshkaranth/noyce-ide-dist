Connect a model

Point Noyce IDE at a local model server, a vLLM box on your network, or a cloud provider, and set the embedding model that powers Semantic Search.

Every AI feature in Noyce IDE, including the Orchestrator agents, Fix with Noyce, document authoring and Semantic Search, runs through the model you configure on the AI Models page. Noyce IDE can run fully offline against a model on your own machine or LAN.

Open it with Noyce AI: Open AI Models from the Command Palette (⇧⌘P on macOS, Ctrl+Shift+P on Windows).

How model requests are routed#

There are two separate kinds of request, and they can go to different servers:

  • Chat (generating text and code) goes to the global model you select, unless that agent role has its own model.
  • Embeddings (turning text into vectors for Semantic Search) go to the server set under Embeddings. A server that only serves a chat model cannot answer them.

Supported providers#

Provider Runs Default endpoint
LM Studio Local http://localhost:1234
vLLM, or any OpenAI-compatible server Local or LAN Use the LM Studio provider and enter the server URL
Ollama Local http://localhost:11434
Open WebUI Local or LAN http://localhost:3000
Google Gemini, Anthropic, OpenAI, OpenRouter Cloud Provider default; needs an API key
Claude CLI, Codex CLI, Gemini CLI Local CLI None; uses the installed CLI

A fresh install starts on LM Studio at http://localhost:1234 with the model set to auto, which uses whatever model the server has loaded.

Tested models#

Noyce IDE has been run end to end on real TI and ST firmware with these models. Any OpenAI-compatible server works; these are the ones it was tested on.

Model Served by What was run on it
Gemma 4 26B A4B LM Studio, on a 24 GB Mac All five pipeline agents and the native AI audit.
Qwen 3.6 35B A3B (NVFP4) vLLM on a DGX Spark An IV&V sweep of office firmware, and development swarms.
Qwen 3.8 27B vLLM on a DGX Spark The PSAC and black-box low-level requirements of a TI Tiva controller.
Qwen 3.8 Flash Next vLLM, over Tailscale Three DO-178C DAL A runs on a TI Tiva controller; all 75 issues they logged are fixed.
Ornith 1.5 35B A3B vLLM with an API key, 262K context All 17 DO-178C documents on the Canister firmware, and the Archify diagram in this manual.

Tip

Reasoning models such as Gemma 4 and Qwen 3.8 can spend their whole token budget thinking. If a model returns empty answers, see A local model returns empty or cut-off answers.

Use a local server (LM Studio, vLLM)#

  1. Start the server and load a model. For LM Studio, enable its local server.
  2. In AI Models, select Loaded model (auto-detect) in the Model Catalog, or pick a specific model.
  3. Under Server URL (LM Studio, vLLM, or any OpenAI-compatible server), enter the address, for example http://localhost:1234 or http://<host>:8000 for vLLM. A trailing /v1 is accepted.
  4. Leave API key empty unless the server was started with --api-key. The key is stored in the operating system keychain and sent only to that server.

Tip

If the server does not report the model's context length, set Context window (tokens) for that model. Noyce IDE sizes every prompt to fit it.

Use a cloud provider#

Choose the provider in the catalog and paste its key into the matching field (Google API Key, Anthropic API Key, OpenAI API Key or OpenRouter API Key).

Warning

Cloud API keys are stored in the operating system keychain, like the local-server key and the per-agent keys. Prefer a local model for proprietary firmware, and switch on Classified in the status bar to have the IDE refuse every cloud provider, including from the agents chat and the hosted CLIs.

Embeddings for Semantic Search#

Semantic Search and agent grounding need an embedding model. Set it in AI Models → Embeddings:

  • Embedding server: the same server as chat, Ollama, LM Studio / vLLM, or OpenAI.
  • Embedding model: defaults to text-embedding-nomic-embed-text-v1.5 on LM Studio, nomic-embed-text on Ollama, and text-embedding-3-small on OpenAI.

Select Save & test. Noyce IDE sends one request and reports the vector size it got back. If you change the embedding model, rebuild the Semantic Search index.

Concurrency and per-agent models#

  • Orchestrator Concurrency sets how many agent calls run at once. It defaults to 3 for local servers and 1 for hosted APIs.
  • Agent Role Assignment gives any of the 15 Orchestrator agents its own model. An agent left on Global default uses the model selected above.
  • Generation Parameters (temperature and max tokens) are shared defaults for global model runs.

The Fixer model select in MISRA Diagnostics overrides the model for Fix with Noyce only.
