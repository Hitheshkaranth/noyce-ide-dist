Projects

The start tab, opening and importing TI, ST and Microchip projects, and how Noyce IDE lays out its surfaces around the editor.

The start tab#

The Noyce IDE tab opens when the IDE starts. Reopen it any time with ⌘⌥N then D, or Noyce: Show Getting Started.

  • Open folder… opens any folder as a project.
  • Import project… starts the import wizard (below).
  • New project opens Project Templates.
  • On a wide window, the keyboard shortcuts for a build, the Compliance Dashboard, the Test Explorer and the Command Palette sit beside them.
  • Recent projects lists what you opened before.
  • Workbench surfaces has a tile per surface, grouped by area; type in Filter surfaces to narrow them. Each tile opens its surface in its own editor tab, so you can arrange surfaces side by side like files.

New Project and Try the demo open demonstration content only; see Known limitations.

Import a project#

The Import Project wizard understands four kinds of project:

Type Recognised by
Code Composer Studio (TI) .ccsproject
STM32CubeIDE (ST) .ioc
MPLAB X (Microchip) nbproject/
Generic folder Any folder of C sources

The wizard analyses the project, opens it, and detects the microcontroller. For a recognised ST or TI part it then downloads that part's reference manual and indexes it for Register Knowledge. The download runs in the background and needs a network connection.

STM32 and Tiva commands#

  • Noyce STM32: Import CubeIDE Project generates .vscode/launch.json and compile_commands.json for an STM32CubeIDE project, set up for OpenOCD.
  • Noyce Tiva: Import Pin Config from Source rebuilds the pin map of a TivaWare project from its C source.
  • Opening an .ioc file opens it straight in the Pin Configurator.
  • Validate Toolchain checks that the Arm GNU tools, debugger and OpenOCD are on your PATH.

Where things are#

Noyce IDE keeps the Code-OSS layout you may know from Visual Studio Code, and adds:

  • Activity bar icons for Noyce IDE, Compliance, Hardware, Noyce AI, Project Graph and Architecture. Each opens views in the sidebar:
Icon View Shows
Noyce IDE Noyce Tools Every tool, grouped into Development, Hardware, Test & Telemetry, and Safety & Collaboration. Select one to open it.
Build Status The 10 most recent builds of the project, TI CCS or STM32CubeIDE, newest first, with the result, the kind, the duration and the time. Hover one for the toolchain and exit code; select it to open the Build view. See Where the output goes.
Project Lifecycle Project Templates, Build Pipeline, Team Activity, Review Workflow and Audit Log.
STM32 Debug State The attached probe, core registers and your memory watches. See Hardware.
Compliance Compliance Every compliance surface, from the Dashboard to Scan Workspace.
Hardware Hardware Every hardware surface.
Serial Ports The serial ports on this machine, checked every 10 seconds. Select one to open it in the Serial Monitor.
Noyce AI Noyce AI AI Orchestrator, Run Agent Pipeline, Agents Chat and AI Models.
Project Graph, Architecture Selecting the icon opens the Project Graph or System Architecture in the editor.
  • Agents in the secondary sidebar: the agents chat and its history.
  • Status bar items: the Classified mode toggle, the CodeGraph symbol count, the Noyce IDE service status (Noyce: ok), the number of serial ports (No Ports when there are none; select it to open the Serial Monitor), and the AI activity with its live token rate.

Every surface can also be opened from the Command Palette. See Commands & shortcuts.

Classified mode#

Switch on Classified in the status bar when the project's source must not leave your machine. While it is on, every call to a cloud model provider is refused: from the Noyce IDE window, from the agents chat panel, and from the hosted Claude, Codex and Gemini CLIs. Local models keep working; see Connect a model.
