Install Noyce IDE

Install Noyce IDE on an Apple silicon Mac or on Windows, add the optional verification tools, and keep it up to date.

Latest releasemacOS arm64Windows x64 (beta)

Noyce IDE ships as a desktop application built on Code-OSS. Pick your platform below. Everything Noyce IDE generates for a project stays inside that project's .noyce/ folder. Nothing is uploaded unless you point the IDE at a cloud model.

System requirements#

macOS Windows
Status Released Beta
Architecture Apple silicon (arm64) only x64
Installer .dmg, 389 MB .exe (system installer), 180 MB
Signing Ad-hoc signed, not notarized Not code-signed
Updates brew upgrade or re-run the installer Run the newer installer

Intel Macs and Linux are not supported by the release builds.

macOS#

Choose one of the three methods. Homebrew is the easiest to keep up to date.

Homebrew (recommended)#

Add the Noyce tap, then install the cask:

Terminal
brew tap Hitheshkaranth/noyce https://github.com/Hitheshkaranth/noyce_ide
brew install --cask noyce-ide

The cask installs Noyce IDE.app into /Applications and clears the macOS quarantine flag for you, so the app opens normally on first launch.

One-line installer#

The script downloads the latest Apple silicon .dmg, copies the app into /Applications (replacing any previous copy), and clears the quarantine flag:

Terminal
curl -fsSL https://raw.githubusercontent.com/Hitheshkaranth/noyce_ide/main/scripts/install/install.sh | bash

Disk image#

  1. Download NoyceIDE-<version>-darwin-arm64.dmg for the latest version from the releases page.

  2. Open the disk image and drag Noyce IDE into Applications.

  3. Clear the quarantine flag before the first launch:

    Terminal
    xattr -dr com.apple.quarantine "/Applications/Noyce IDE.app"

Warning

The macOS build is ad-hoc signed and not notarized. If you skip step 3, macOS reports that the app "is damaged" or comes from an unidentified developer and refuses to open it. Homebrew and the one-line installer run this step for you.

Windows (beta)#

  1. Download NoyceIDE-<version>-win32-x64-system-<commit>.exe for the latest version from the releases page.
  2. Run the installer. It installs for all users, so Windows asks for administrator approval.
  3. If Microsoft Defender SmartScreen shows Windows protected your PC, select More info, then Run anyway.

Warning

The Windows installer is not code-signed yet, which is why SmartScreen warns. Windows support is in beta.

First launch#

Open Noyce IDE from Applications or the Start menu. The Noyce IDE tab opens with Open folder…, Import project… and New project, your recent projects, and a tile for every workbench surface. Continue with the Quick start.

Optional tools#

Noyce IDE runs without any of these. Each one switches on a specific kind of evidence; when a tool is missing, the surface that needs it says so and nothing is faked.

Tool Used by How Noyce IDE finds it Install
CBMC 6.9.0 Formal Verification vendor/cbmc, then PATH Install CBMC in the view, or brew install cbmc (macOS), or winget Diffblue.CBMC (Windows)
CodeQL CLI 2.25.6 Code Scanning vendor/codeql, then PATH Install CodeQL in the view downloads the official bundle and checks its SHA-256
LLVM/Clang 18 or newer (clang, llvm-profdata, llvm-cov) MC/DC Coverage PATH, then Homebrew's llvm, then xcrun brew install llvm (macOS) or the LLVM release installer (Windows)
cppcheck MISRA Diagnostics PATH brew install cppcheck. Without it, a built-in heuristic scan runs and is labelled as heuristic, not evidence
Arm GNU toolchain, make, OpenOCD STM32 build and debug PATH, then STM32CubeIDE and Arm toolchain folders Install from Arm or ST
TI compiler (armcl / tiarmclang) and TivaWare TI Tiva builds, Build Pipeline ~/ti, /Applications/ti, C:\ti Install Code Composer Studio

A debug probe needs no separate install: probe-rs is built into the IDE. OCR for schematics is bundled as well.

Note

If GCC and gcov are installed but LLVM is not, coverage still reports statements and branches, and MC/DC reads "MC/DC unavailable" with the reason. gcov cannot measure MC/DC at any version.

Connect a model#

The AI features need a model. Noyce IDE starts pointed at LM Studio on http://localhost:1234; any OpenAI-compatible server (vLLM included) works the same way. See Models.

Update#

  • Homebrew: brew upgrade --cask noyce-ide
  • One-line installer: run the same command again; it replaces the app with the latest release.
  • Disk image or Windows: download and run the newer release.

There is no in-app updater. Your settings and every project's .noyce/ folder are kept across updates.

Uninstall#

macOS#

Terminal
# Homebrew: remove the app
brew uninstall --cask noyce-ide
# or remove the app and its settings
brew uninstall --zap --cask noyce-ide
# extensions and per-user data live here, and are not removed by --zap
rm -rf ~/.noyce-ide

If you installed from the disk image or the one-line installer, drag /Applications/Noyce IDE.app to the Bin, then delete ~/Library/Application Support/Noyce IDE and ~/.noyce-ide if you want your settings gone too.

Windows#

Open Settings → Apps → Installed apps, find Noyce IDE, and choose Uninstall. Settings stay in %APPDATA%\Noyce IDE and extensions in %USERPROFILE%\.noyce-ide; delete those folders to remove everything.

Tip

Uninstalling never touches your projects. Each project's generated evidence stays in its own .noyce/ folder until you delete it.
