Commands and shortcuts

Every Noyce IDE command you can run from the Command Palette, with its keyboard shortcut. Generated from the extension manifests.

Open the Command Palette with ⇧⌘P on macOS or CtrlShiftP on Windows, then type any title below. Most Noyce IDE shortcuts are two-step chords: press ⌘⌥N (CtrlAltN on Windows), release, then press the letter.

Limitation

Some chords are bound to two commands, so pressing them runs only one of the two. Use the Command Palette for the other:

  • ⌘⌥N M: Open MISRA Diagnostics and Open Firmware Memory & Stack
  • ⌘⌥N P: Open Pin Configurator and Show Project Graph
